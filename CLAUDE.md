A colleague Stefan Bekiranov and I (Aakrosh Ratan) are co-leading a module in the UVA BIMS Core-Course (BIMS 6000) on computational Biology. Here is the overview of the block:

Block 3.5 - Computational Biology is going to be somewhat different than the other blocks in the core course.   This block is not going to focus on specific biological content that we want you to incorporate into your foundation of biological understanding, therefore there will be no reading in the Alberts textbook or foundational self-assessment. Rather, the goal of this block is to have you become familiar, or improve your skills, with a set of tools that are becoming indispensable for modern biomedical research.  These skills include: learning how to access the UVA High-Performance Computing system, Rivanna, learning how to navigate and manipulate files in the UNIX shell, and basic programming using R and RStudio.  This block will culminate in using these tools for RNA-seq data analysis, much as you would if you were analyzing data from your own experiments.  We recognize that students will be coming in to this block with broad range of computational experience, therefore we do not expect that you will necessarily finish this block with proficiency in UNIX and R programming.  Rather, we hope that this introduction will facilitate your using these tools when you need them in your own research.
